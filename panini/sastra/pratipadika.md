# prātipadika · Іменна основа · Nominalstamm

## English

`prātipadika` is a technical `saṃjñā` (designation) for a nominal stem, not an assumed programming primitive. 

The Aṣṭādhyāyī defines it in two parts:
1. **1.2.45** *arthavad adhātur apratyayaḥ prātipadikam*: A meaningful form that is neither a verbal root (`dhātu`) nor an affix (`pratyaya`) is called a `prātipadika`.
2. **1.2.46** *kṛttaddhitasamāsāśca*: Forms ending in `kṛt` affixes, `taddhita` affixes, and compounds (`samāsa`) are also designated as `prātipadika`.

Later sūtras use this category as a rule condition (e.g., 1.2.47 *hrasvo napuṃsake prātipadikasya* - a neuter prātipadika gets a short vowel). However, this does not make it a free lexical object outside of the derivation process. "Nominal base" is a useful gloss, but not an interchangeable definition. The designation must be formally acquired by a linguistic unit through these rules before case suffixes (`sup`) can be added.

## Українська

`prātipadika` — технічна категорія (`saṃjñā`), а не базовий програмний примітив.

Паніні визначає її двома сутрами:
1. **1.2.45** *arthavad adhātur apratyayaḥ prātipadikam*: Її мінімальні умови сформульовано водночас позитивно й негативно: форма має значення (*arthavat*) і не є ані коренем (*adhātu*), ані суфіксом (*apratyaya*).
2. **1.2.46** *kṛttaddhitasamāsāśca*: Наступна сутра окремо надає позначення `prātipadika` відповідним утворенням із суфіксами `kṛt`, `taddhita` та композитам (`samāsa`). Це два різні джерельні факти.

Локальний корпус містить пізніші вживання категорії як умови для інших правил (наприклад, 1.2.47 *hrasvo napuṃsake prātipadikasya*). Це показує, що категорію використовують як умову для деривації, але це не робить її вільним лексичним об'єктом. «Номінальна основа» — корисний глос, але не взаємозамінний переклад. Щоб додати відмінковий суфікс (`sup`), форма повинна спочатку легально набути статусу `prātipadika`.

## Deutsch

`prātipadika` ist eine technische Bezeichnung (`saṃjñā`) für einen Nominalstamm, kein vorausgesetztes Programmierprimitiv.

Die Aṣṭādhyāyī definiert es in zwei Teilen:
1. **1.2.45** *arthavad adhātur apratyayaḥ prātipadikam*: Eine bedeutungstragende Form, die weder Verbalwurzel (`dhātu`) noch Affix (`pratyaya`) ist, wird `prātipadika` genannt.
2. **1.2.46** *kṛttaddhitasamāsāśca*: Formen, die auf `kṛt`-Affixe, `taddhita`-Affixe enden, sowie Komposita (`samāsa`) werden ebenfalls als `prātipadika` bezeichnet.

Spätere Sūtras verwenden diese Kategorie als Regelbedingung (z.B. 1.2.47 *hrasvo napuṃsake prātipadikasya*). Dies macht sie jedoch nicht zu einem freien lexikalischen Objekt außerhalb des Ableitungsprozesses. "Nominaler Stamm" ist eine nützliche Umschreibung, aber keine austauschbare Definition. Die Form muss diese Bezeichnung formal durch die Regeln erlangen, bevor Kasussuffixe (`sup`) angehängt werden können.
