## File 1 — karaka-counterexamples.md

IAST normalisation: `bālena pustakaṃ paṭhyate`; `rāma odanaṃ devadattena
pācayati`; `odanaṃ bhuñjāno viṣaṃ bhuṅkte`; `corād bībheti`.

§1 Passive (kartṛ ≠ subject)
- `bālena` = instrumental sg of bāla (boy); `paṭhyate` = passive 3sg of paṭh.
  The agent of reading is expressed in the instrumental and is the kartṛ; the
  nominative `pustakam` (karman) is the grammatical subject. Standard Pāṇinian
  passive analysis. AGREE. ✓
- sūtra 1.4.54 `svatantraḥ kartā` — correct number and text. ✓

§2 Causative (agent splits)
- `rāma` nominative = instigator (kartṛ/hetu); `devadattena` instrumental = the
  caused physical performer; `odanaṃ` accusative = karman; `pācayati` causative
  of pac. The causer/hetu vs caused-kartṛ distinction is exactly 1.4.55. AGREE. ✓
- sūtra 1.4.55 `tatprayojako hetuś ca` — correct. ✓

§3 karman undesired object
- `viṣaṃ` (poison) is not the deliberate object but is karman because linked to
  the action in the same way as the desired object — fits 1.4.50
  `tathāyuktaṃ cānīpsitam`. Correct citation and reasoning. AGREE. ✓

§4 double accusative
- sūtra 1.4.51 `akathitaṃ ca` — the "unspoken" karman for the second accusative
  in double-accusative constructions. Correct number and sense. The file
  correctly notes it verified the number via 1.4.50 work but not the text
  independently — honest. AGREE. ✓

§5 apādāna fear (no physical motion)
- `corād` ablative = cause of fear = apādāna by 1.4.25 `bhītrārthānāṃ
  bhayahetuḥ`. Correct number and content. Base 1.4.24 (separation) vs extended
  1.4.25 (fear source) distinction is standard. AGREE. ✓

Conclusion File 1: all sūtra numbers/contents correct; all five analyses
grammatically sound. No Sanskrit error found.
