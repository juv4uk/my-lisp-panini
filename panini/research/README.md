# Research / Дослідження / Forschung

## English

This directory records evidence-led research for Panini Foundation. Every
substantive claim must preserve the boundary between `[PANINI]`,
`[INTERPRETATION]`, and `[MY-LISP HYPOTHESIS]`. Analyses of Vidyut, Sanskrit
Heritage, and Panini-NLP are implementation studies, not replacement primary
sources. Start with [vidyut-analysis.md](vidyut-analysis.md),
[citation-provenance.md](citation-provenance.md), and
[computational-hypotheses.md](computational-hypotheses.md).
The thematic [research map](research-map.md) provides a trilingual entry point
to the full audit set.
