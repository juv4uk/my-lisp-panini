## 🇺🇸 English: Source Selection for Causative
### Selected Derivation
**Target Word**: `bhāvayati` (he causes to be)
**Root**: `bhū` (to be) + causative suffix `ṇic` (3.1.26 *hetumati ca*)

### Sūtra Chain (Core)
1. 3.1.26 `hetumati ca` — Adds `ṇic` suffix to a root when a causative agent (hetu) is present.
2. 7.2.115 `aco ñṇiti` — Vṛddhi substitution for ending vowels before `ñ` or `ṇ` marked affixes (bhū → bhau).
3. 6.1.78 `eco'yavāyāvaḥ` — Sandhi: bhau + a → bhāv + a.
4. (Standard present tense derivations follow: `laṭ`, `śap`, `tip`, resulting in `bhāvayati`).

### Commentary & Lexical Sources
- **Traditional**: Siddhānta Kaumudī (Bhaṭṭoji Dīkṣita), section on ṇijanta (causatives).
- **Computational**: Vidyut documentation on secondary roots (sannanta, ṇijanta).
- **Lexical**: Dhātupāṭha (bhū - 1.1).

### Unresolved Points
- Does `ṇic` create a new `dhātu` (secondary root) which then undergoes the entire normal derivation process recursively, or is it processed in a single pass? (Pāṇini 3.1.32 *sanādyantā dhātavaḥ* says forms ending in `san`, etc., are called `dhātu`). This is a crucial architectural decision for the `meta.my` engine (recursive grammar vs flat generation).

## 🇺🇦 Українська: Вибір джерела для каузатива
### Вибрана деривація
**Цільове слово**: `bhAvayati` (він змушує бути)
**Корінь**: `bhū` (бути) + каузативний суфікс `Ric` (3.1.26 *hetumati ca*)

### Ланцюг сутр (Основний)
1. 3.1.26 `hetumati ca` — Додає суфікс `Ric` до кореня при наявності каузативного агента (hetu).
2. 7.2.115 `aco YRiti` — Vṛddhi-заміна для кінцевих голосних перед афіксами з маркерами `Y` або `R` (bhū → bhau).
3. 6.1.78 `eco'yavAyAvaH` — Сандхі: bhau + a → bhAv + a.
4. (Далі йдуть стандартні деривації теперішнього часу: `laT`, `Sap`, `tip`, що дають `bhAvayati`).

### Джерела коментарів та лексики
- **Традиційні**: Siddhānta Kaumudī (Bhaṭṭoji Dīkṣita), розділ про ṇijanta (каузативи).
- **Обчислювальні**: Документація Vidyut про вторинні корені (sannanta, ṇijanta).
- **Лексичні**: Dhātupāṭha (bhū - 1.1).

### Невирішені питання
- Чи створює `Ric` новий `dhātu` (вторинний корінь), який потім рекурсивно проходить весь нормальний процес деривації, чи це обробляється за один прохід? (Паніні 3.1.32 *sanādyantā dhātavaḥ* каже, що форми, які закінчуються на `san` тощо, називаються `dhātu`). Це критичне архітектурне рішення для рушія `meta.my` (рекурсивна граматика проти плоского генерування).

## 🇩🇪 Deutsch: Quellenauswahl für das Kausativ
### Ausgewählte Ableitung
**Zielwort**: `bhāvayati` (er lässt sein / er bewirkt)
**Wurzel**: `bhū` (sein) + Kausativsuffix `ṇic` (3.1.26 *hetumati ca*)

### Sūtra-Kette (Kern)
1. 3.1.26 `hetumati ca` — Fügt der Wurzel das Suffix `ṇic` hinzu, wenn ein kausativer Agent (hetu) vorhanden ist.
2. 7.2.115 `aco ñṇiti` — Vṛddhi-Ersatz für Endvokale vor Affixen, die mit `ñ` oder `ṇ` markiert sind (bhū → bhau).
3. 6.1.78 `eco'yavāyāvaḥ` — Sandhi: bhau + a → bhāv + a.
4. (Danach folgen Standardableitungen des Präsens: `laṭ`, `śap`, `tip`, was zu `bhāvayati` führt).

### Kommentare & Lexikalische Quellen
- **Traditionell**: Siddhānta Kaumudī (Bhaṭṭoji Dīkṣita), Abschnitt über ṇijanta (Kausative).
- **Computergestützt**: Vidyut-Dokumentation über sekundäre Wurzeln (sannanta, ṇijanta).
- **Lexikalisch**: Dhātupāṭha (bhū - 1.1).

### Ungelöste Punkte
- Erzeugt `ṇic` ein neues `dhātu` (sekundäre Wurzel), das dann rekursiv den gesamten normalen Ableitungsprozess durchläuft, oder wird es in einem einzigen Durchgang verarbeitet? (Pāṇini 3.1.32 *sanādyantā dhātavaḥ* besagt, dass Formen, die auf `san` usw. enden, `dhātu` genannt werden). Dies ist eine entscheidende architektonische Entscheidung für die `meta.my`-Engine (rekursive Grammatik vs. flache Generierung).
