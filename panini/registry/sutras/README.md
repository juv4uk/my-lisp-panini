# Local sūtra index / Локальний індекс sūtra / Lokaler Sūtra-Index

## English

`index.yaml` is a working local index of the Aṣṭādhyāyī. It is not a critical
edition and not a demonstrated authority for translations or rule types. For
its exact status, reproducibility limits, and use rules, see
[`../../research/sutra-local-corpus-provenance.md`](../../research/sutra-local-corpus-provenance.md).

`citation-provenance.yaml` is the mandatory citation layer for documents that
cite sūtra. Do not add or mass-"correct" text in `index.yaml` without a source,
a reproducible import, and a separate audit.

## Українська

`index.yaml` — робочий локальний індекс Aṣṭādhyāyī. Це не критичне видання і
не доведене джерело для перекладів чи типів правил. Для точного стану,
обмежень відтворюваності та правил використання див.
[`../../research/sutra-local-corpus-provenance.md`](../../research/sutra-local-corpus-provenance.md).

`citation-provenance.yaml` є обов'язковим шаром посилань для документів, що
цитують sūtra. Не додавайте і не «виправляйте» масово текст `index.yaml` без
джерела, відтворюваного імпорту та окремого аудиту.

## Deutsch

`index.yaml` ist ein lokaler Arbeitsindex der Aṣṭādhyāyī. Er ist weder eine
kritische Ausgabe noch eine nachgewiesene Autorität für Übersetzungen oder
Regeltypen. Den genauen Status, Grenzen der Reproduzierbarkeit und
Nutzungsregeln beschreibt
[`../../research/sutra-local-corpus-provenance.md`](../../research/sutra-local-corpus-provenance.md).

`citation-provenance.yaml` ist die verpflichtende Zitatebene für Dokumente,
die Sūtra zitieren. Ergänze oder „korrigiere“ den Text in `index.yaml` nicht
massenhaft ohne Quelle, reproduzierbaren Import und gesondertes Audit.
